Git-SVN Shuttle 0.3.9

- 여러 Git-SVN 저장소 중 게시할 저장소만 선택하고 선택 순서대로 dcommit할 수 있습니다.
- 저장소 행을 펼쳐 실제 게시 순서의 대기 커밋을 확인할 수 있습니다.
- 넓은 폭과 420px 도구 창에서 모두 동작하는 평면형 저장소 테이블 UI로 전면 개편했습니다.
- 준비, 재검증, 게시 진행과 저장소별 성공·실패·취소 결과를 표시합니다.
- 작업 취소 시 현재 Git 프로세스를 중단하고 실행하지 않은 후속 저장소를 구분합니다.
- Visual Studio 없이 실제 제품 XAML을 밝은/어두운 테마와 여러 폭으로 확인하는 WPF 프리뷰 호스트를 추가했습니다.

Git-SVN Shuttle 0.3.5

- SVN 게시 후 현재 Git 브랜치가 게시 전 커밋에 남아 새로 고침으로도 갱신되지 않던 문제를 수정했습니다.

Git-SVN Shuttle 0.3.4

- 다른 Windows 언어 설정에서도 한글 커밋 작성자와 제목을 UTF-8로 표시합니다.
- git svn rebase 충돌을 구분해 충돌 파일을 보여주고, 해결 후 계속하거나 확인 후 중단할 수 있습니다.
- 솔루션에 정션으로 연결된 외부 저장소의 하위 프로젝트도 제한된 경로에서 안전하게 찾습니다.

Git-SVN Shuttle 0.3.3

- Visual Studio Marketplace의 한국어 짧은 설명이 깨지는 문제를 수정했습니다.

Git-SVN Shuttle 0.3.2

- Git과 git svn의 사용 가능 여부를 도구 창에서 자동으로 진단합니다.
- git.exe 직접 선택, 자동 검색, 재검사, 기본값 재설정 UI를 추가했습니다.
- 확인 화면과 실행 시점 사이의 저장소 상태를 다시 검증하고 확인된 HEAD를 고정해 dcommit합니다.
- junction/reparse-point 탐색을 차단하고 저장소 탐색 범위를 제한합니다.
- Git 프로세스의 시간 제한, 취소, 출력 크기 제한, 비대화형 실행을 적용했습니다.
- Output 로그의 자격 증명 형태 값과 SVN URL 사용자 정보를 제거합니다.
- 파일 시스템 알림 기반으로 저장소 상태를 가볍게 갱신합니다.
