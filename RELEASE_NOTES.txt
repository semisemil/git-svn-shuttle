Git-SVN Shuttle 0.5.2

- 저장소 조회, 게시 준비와 확인 창의 상태 검증을 최대 두 작업 사본에서 병렬 처리해 대기 시간을 줄였습니다.
- 중복 상태 조회와 전체 대상 재검증을 정리했습니다. 확정 후 대상별 dry-run 1회, 모든 대상의 검사 완료 후 첫 게시, 게시 직전 검사와 순차 dcommit은 유지합니다.
- 변경되지 않은 SVN 기준 커밋의 표시 정보를 재사용하고, 로컬 이력과 revision map을 검증해 게시 대상을 빠르게 조회합니다. 확인할 수 없는 경우 기존 Git-SVN 조회를 사용합니다.
- Git for Windows 2.51.2용 Git-SVN 시작 옵션 조회 최적화 스크립트를 별도로 제공합니다. 원본 백업과 복구를 지원하며, 외부 Git 최적화는 스크립트로 별도 적용합니다.
- 원본과 최적화 Git-SVN의 설정 해석, 실제 SVN 게시와 로컬 작업 상태 보존을 통합 검증합니다.

Git-SVN Shuttle 0.5.1

- SVN 연결 관리 화면에서 확인할 수 있는 원본과 브랜치 저장 위치를 자동으로 채웁니다. 후보가 여러 개면 사용할 경로를 선택합니다.
- 리비전, 생성 메시지, 로컬 Git 이름과 브랜치 전환 옵션을 고급 설정으로 옮기고 생성 주소를 미리 표시합니다.
- 연결 설정에 기본 폴더 구조와 단일 SVN 주소 선택을 추가했습니다. 사용자 지정 추적 경로는 고급 설정에서 편집합니다.
- 조회 진행 상태, 오류별 다음 행동과 재조회 버튼을 표시합니다. 연결 조회는 최대 20초 동안 기다리며 작업 중에도 취소와 닫기를 사용할 수 있습니다.
- 주요 실행 버튼을 화면 하단에 고정하고, 생성 완료 또는 결과 불확실 상태에서 같은 서버 주소의 중복 생성을 막습니다.

Git-SVN Shuttle 0.5.0

- 저장소별 trunk, branches, tags 추적 경로를 조회·변경하고, 기존 배치와 새 배치를 함께 추적할 수 있습니다.
- 경로 전환 중 로컬 커밋, 스테이징, 미커밋 변경과 기존 SVN 이력의 전송 연결을 보존합니다.
- 원본 경로와 리비전을 지정해 SVN 원격 브랜치를 생성하고 로컬 작업 브랜치에 연결합니다. 브랜치 생성에는 SVN 명령줄 클라이언트가 필요합니다.
- 현재 작업 브랜치의 실제 dcommit 대상 URL을 표시하고 게시 확인에 반영합니다.
- 기존·신규·혼합 SVN 배치의 브랜치 생성, 경로 이전, 작업 상태 보존과 실제 dcommit을 통합 테스트로 검증합니다.
